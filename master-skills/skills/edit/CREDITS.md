# Credits

The edit skill combines ideas from three editing skills. No upstream text or code is copied into
this folder. The workflow, tools and wording are original, and each upstream project is linked
for its deep version.

| Project | License | What this skill learned from it | Link |
|---|---|---|---|
| HyperFrames (HeyGen) | Apache-2.0 | HTML-to-video as the default motion engine; route captions, overlays and motion graphics to its skills; word-level transcript reuse | https://github.com/heygen-com/hyperframes |
| Remotion Agent Skills | no license file: linked only, nothing copied | React-based motion for users already on Remotion | https://github.com/remotion-dev/skills |
| video-use (Browser Use) | MIT | transcript-first editing, cut at word boundaries with padding, short fades at every join, an EDL, confirm the plan first, self-check the render | https://github.com/browser-use/video-use |

Install commands quoted in SKILL.md come from each repository's README (checked October 2026).

House taste rules (pacing, safe zone, captions, motion, audio chain) come from the shipped reels
of Jake Schincariol (@opusjake).

The tools in `tools/` are MIT licensed as part of
[Jakeschincariol/master-skills](https://github.com/Jakeschincariol/master-skills).
